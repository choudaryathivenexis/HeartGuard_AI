# HeartGuard AI - Python dependencies
# Install with:  pip install -r requirements.txt
# Tested with Python 3.11-3.14
#
# NOTE: the trained model artifacts in models/ (*.pkl, scaler.pkl) were serialized with
# scikit-learn 1.9.0. Loading them under an older version raises
# InconsistentVersionWarning and may give invalid results, so the floor below is set
# accordingly. If you retrain from scratch (train_models.py), any recent version works.

# --- Web framework (backend) ---
# Flask serves the application and renders Jinja templates. Jinja2, Werkzeug,
# itsdangerous, click and blinker arrive as Flask's own dependencies.
flask>=3.0

# Production WSGI server. Flask's built-in server is Werkzeug's development
# server: single-process and not hardened for exposure. Waitress rather than
# gunicorn because gunicorn does not run on Windows.
waitress>=3.0

# --- Database ---
# SQLite needs nothing: it is in the standard library, and it is what the application
# uses when DATABASE_URL is unset — which is every local run.
#
# Postgres is what it uses when DATABASE_URL IS set, which is every deployment to a
# host with a read-only filesystem. [binary] ships the libpq wheel so no PostgreSQL
# client library has to be present on the machine. psycopg_pool keeps a handful of
# connections open; without it every repository call pays a fresh TCP and TLS
# handshake, and one page makes several.
psycopg[binary]>=3.2
psycopg_pool>=3.2

# --- Data handling ---
pandas>=2.0
numpy>=1.24

# --- Machine learning ---
# PINNED, not a floor. These two libraries WROTE the pickles in models/, and both
# validate the version that unpickles them: scikit-learn raises
# InconsistentVersionWarning and may return invalid results, and xgboost rejects a
# Booster saved by a different major version outright. A floor of >=1.9.0 installs
# whatever is newest at build time, so a deployment months from now would silently
# score patients with mismatched estimators. Retraining with train_models.py is what
# licenses moving these numbers.
scikit-learn==1.9.0
xgboost==3.3.0

# --- Explainable AI ---
shap>=0.44

# --- Plotting and PDF ---
# matplotlib renders both the chart images and the multi-page clinical PDF (via
# PdfPages), so no separate PDF library is needed.
matplotlib>=3.7

# --- Fonts / favicon generation ---
# Pillow arrives with matplotlib and is used by frontend/design/brand.py to render the
# favicon. Listed explicitly because the code imports it directly.
pillow>=10.0
